# Changes — 2026-08-17 (feat/desktop-analyst)

## Artha `.dmg` installer + import-from-prod

Made the desktop-analyst app a real installable Mac app, plus an empty-shell +
import flow to seed it from production (Bharath's chosen approach — don't bake
personal data into a shareable bundle).

**Packaging (`a74de6f`, `9f4f92b`):**
- electron-builder config in package.json (`main=electron/main.js`, unsigned
  arm64 dmg, `asar:false`, `npmRebuild:false`). `npm run dist:mac` →
  `electron-dist/Artha-0.1.0-arm64.dmg` (314MB).
- Two packaging bugs found + fixed: electron-builder strips node_modules from
  extraResources (→ "Cannot find module 'next'"), and Next's standalone traces
  the whole repo into itself (incl. electron-dist → infinite self-copy). An
  `electron/after-pack.js` hook copies only the standalone runtime essentials
  (server.js, .next, node_modules, package.json, public) into Resources.
- Verified: packaged Artha.app boots (70 migrations, Next server, /api/health
  200, window, cron ticker), demo login + gold + dashboard all 200.

**Import from prod backup:**
- `scripts/backup-prod.sh` — pg_dump vaspar-pfd (full schema+data, `--inserts`)
  to a file.
- `POST /api/desktop/import-db` + `/import-data` page — upload a backup; it drops
  the local schemas, replays the dump, and marks all migrations applied. Restores
  prod's OWN schema, sidestepping drift between prod and the migration files
  (prod has columns like `form_16_uploads.file_bytes` the .sql files don't
  create). `proxyClientMaxBodySize` raised to 512mb for the ~40MB dump.
- Verified end-to-end on the running app: import 117 tables / 2 accounts; the
  Personal account then shows prod gold + `/investments/analyst` 200.

**Known limits / TODO:** arm64-only (Intel needs a separate target); unsigned
(first open needs right-click → Open, or notarize for distribution); default
Electron icon (no branding yet); `/import-data` isn't linked in the nav yet.
