# Changes — 2026-08-15 (feat/desktop-app)

## Desktop app: no-Docker, cross-platform, PGlite-embedded (scaffold + proven)

Goal: make pfd-saas installable as a single app bundle on any computer (Win/Mac),
no Docker, no external Postgres — while keeping the code multi-tenant (multi-user
within one local install). Branch `feat/desktop-app` off `main`; the SaaS/Docker
path is untouched (identical `DATABASE_URL` + `postgres-js` client).

**Architecture (validated, zero app-code change):**
- Electron main embeds **PGlite** (Postgres-in-WASM) at `<userData>/pgdata`,
  applies migrations, and serves it over a **localhost Postgres-wire socket**
  (`@electric-sql/pglite-socket`). The Next standalone server connects with the
  **unchanged** `postgres-js` client via `DATABASE_URL` — PGlite is invisible to
  the app. Chosen over a driver swap so SaaS + desktop share identical DB code.
- Cross-platform for free: PGlite is pure WASM/JS — nothing native per-OS.
- Electron over Tauri because the app is a Next.js *server* (needs Node); Tauri
  would require a Node sidecar for no gain.

**New files:**
- `electron/db-bootstrap.mjs` — first-boot migrator (applies migrations via
  PGlite `exec()` since repo migrations lack drizzle `--> statement-breakpoint`
  markers; tracks applied files in `__pfd_migrations`) + socket server + `dump()`.
- `electron/main.js` — migrate → PGlite+socket → spawn Next standalone against
  the socket → window on `/api/health` 200. Local Demo/Personal chooser
  (`DEMO_PERSONAL_SWITCH`), no email, `DISABLE_CRON=true`.
- `scripts/pglite-spike.mjs`, `scripts/pglite-socket-test.mjs`,
  `scripts/desktop-smoke.mjs` — the validation harness.

**Proven (evidence):**
- 49 migrations apply on PGlite in ~2s → 91 tables == main exactly (the 25-table
  gap vs prod is precisely the analyst-only `agent_*` tables).
- Backup/restore both ways: `dumpDataDir()` (.tar.gz) + `pgDump()` (portable .sql,
  restorable into real Postgres).
- `postgres-js` ↔ PGlite over socket: SELECT, count, parameterized (Drizzle path),
  INSERT…RETURNING.
- Full headless boot: migrate → serve → auth (switch to Demo) → demo-seed through
  PGlite → authed DB reads (1 gold, 5 stocks). `/api/health` ok, `/login` 200.
- Real Electron launch: window up, `db: up`, ~1.27 GB RSS.

**Fixed along the way:** an untracked stray `_rs-compare.ts` (imported analyst-only
modules) broke the main-based build — moved out of the tree.

**Remaining:** electron-builder packaging (`.dmg` + Windows NSIS), in-app
backup/restore UI, and a Windows build/test (needs a Windows box or CI —
configurable here, not truthfully testable on this Mac).
